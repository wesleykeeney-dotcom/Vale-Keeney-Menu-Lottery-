## Reconciliation rules

1. **Do not equate** a same-theme dinner, a named variant, a cookbook index number, and a lottery ID without source evidence.
2. **Do not hide** mushroom-containing original ingredients. The archive retains them; household shopping withholds those original products only where the absence is explicitly flagged as **not cook-ready** and a replacement decision is unresolved.
3. Recovered manuscript text does **not** establish independently verified source-image fidelity. An empty structured Vault record is an open reconciliation task, not proof that a source has no ingredients.
4. Pantry matching tracks ingredient **names**, not quantities or portions; partial and unmapped meals remain unscored.
5. User approval of a mushroom-free adaptation must create a separate household recipe choice. Never overwrite a locked or original source formulation.
6. Newly recovered ingredients require quantity-by-quantity tests, original/household separation, 84-ID continuity, and phone shopping QA.

This register can guide future recipe-image recovery without silently promoting uncertain lists to verified originals.
