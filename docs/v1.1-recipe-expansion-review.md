## Guardrails / QA interpretation

- A source identity match is not a method-verification gate.
- A full household *shopping template* is not a full cooking recipe.
- A named alternative ("marinara or pizza sauce") is not permission to alter source text without stating the chosen household variant.
- Existing approved cooking content (#6) and all 84 immutable lottery positions stay unchanged until a separately authorized code change.
- This review stores **no unapproved cooking methods or ingredient bodies** in public repository files, and does not access the private Vault from a public browser.
- **Docs-only changes do not require a service-worker cache bump or Android acceptance**; publication of an actual new recipe does.

**This PR is a development review gate, not a request to merge unapproved recipe contents.**
